# 曜核：2.8.0 品牌与兼容约定

曜核 是本地 AI 资产与协作工作台，前身为 AI Hub。它统一呈现工作区、可复用模型、出图来源、报告、任务交接和经审核的共享记忆；具体作品的文稿、分镜及制作进度由相应创作工具管理。

本说明记录 2.8.0 的品牌升级。当时只做本地显示品牌、图标和界面更新，没有单独发布 2.8.0 安装包；2.9.0 候选包包含这些品牌改动并加入托盘。当前候选主程序与 MCP bridge 为 2.11.1，桌面壳为 2.11.0.0。下表的版本字段保留为 2.8 历史记录。协作能力及其权限边界继续适用；新版视觉不代表增加系统隔离、全盘监控或自动控制其他软件。

## 显示与视觉

- 产品显示名统一使用纯中文“曜核”，不添加英文尾缀。AI Hub 仅用于旧名称说明、历史记录和兼容技术标识。
- 用户选择的 E01 以金色眼睛为视觉主体；眼形轮廓与内部光点构成统一标识。产品名为“曜核”，不再从眼形衍生其他显示名称。
- 深靛作为主背景与层次基底，金杏用于主要操作和选中重点，珊瑚用于少量点缀。正文、辅助文字、边界和焦点仍须清晰，不能只用颜色表达成功、警告或错误。
- 保持模型表格和元数据可读、大图预览完整、表单标签明确。装饰不占据关键业务区域，不掩盖扫描不完整、未接入、空结果及错误状态。
- 图标在窗口、侧栏、favicon 和 EXE 中保持同一识别形态；小尺寸下检查轮廓与透明边缘。既有模型、图库与项目图片不作品牌素材，不改变原文件。
- 侧栏眼内允许克制的短暂闪烁与短拖影，动效只用于品牌装饰，不表示运行、连接或任务状态。窗口图标与 favicon 保持可辨的静态标识；启用 `prefers-reduced-motion: reduce` 时，侧栏闪烁与拖影也应静止，不以其他动画替代。
- 不增加在线字体、运行时设计依赖或资源下载。已有返回、筛选、滚动恢复、详情编辑、右键菜单及协作功能保持原行为。

## 集成验收

源码、构建产物、本机安装、服务版本与真实窗口是不同验收层次。完成代码检查后，还需要验证实际 EXE 的产品/文件版本、嵌入图标和窗口标题，以及正式健康接口的版本。

界面至少检查工作总览、模型详情与右键菜单、出图库、协作来源表、空结果和错误提示；同时检查不同窗口尺寸下的导航、长名称、滚动、表格与焦点。必须保留来源的扫描数量和“未完整”提示，不能把配置已写入显示为客户端已握手。

动效验收还应检查 E01 眼内闪烁与拖影的范围、持续时间和文字可读性，并确认减少动态效果设置下保持静态。未完成真实窗口验收时，不把动效规范写成已经通过的结论。

程序与桌面壳更新前保留可回退代码和配置；运行中的 EXE 不能直接覆盖。服务重启前确认后台任务状态，数据库备份使用 SQLite backup API。回退只恢复对应代码与桌面壳，不用旧库覆盖新数据。

现有自动检查为 Python unittest、Node 测试和前端语法检查；桌面更改另运行使用已校验离线 SDK 的构建测试。包内应包含新图标、主题与本文档，仍排除本机配置、数据库、报告、备份、模型、图库和浏览器状态。自动检查不代替真实窗口视觉验收。

## 2.11.1 开场动效

完整载入页面时以现有 E01 金色眼形做一次短暂开场，柔光、掠光和文字显现后平滑退出。动效不充当服务进度条，不等待或延迟数据请求，不绑定导航切换或托盘恢复。点击、按键或切到后台立即结束；减少动态效果直接跳过。没有动画脚本或样式时也必须保持工作台可用。
