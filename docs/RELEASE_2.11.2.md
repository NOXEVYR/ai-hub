# 曜核 2.11.2

启动窗口以原生金色眼形动效替代“正在打开本地工作空间”“正在加载工作台”等常规文字。

- 动效显示在真实加载等待期间；服务和页面就绪后立即停止并进入工作台，不增加人为等待时间。
- 移除加载完成后才显示的网页开场层，不再需要点击跳过，切换栏目和托盘恢复也不追加片头。
- 使用现有 E01 图标与轻量光效，不新增浏览器请求、媒体、字体或运行依赖。
- 托盘隐藏、最小化和窗口关闭停止动画计时；仍在加载时恢复才继续。减少动画设置下使用静态图标。
- 真正加载失败时仍显示错误说明和重试入口，不用动画掩盖失败。

主程序、MCP 桥与桌面壳为2.11.2，程序集2.11.2.0。更新保留用户配置、数据库、图库、模型和工作端记录。
