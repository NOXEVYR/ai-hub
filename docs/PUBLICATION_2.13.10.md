## 发布工作流前置条件

首次发布校验包通过后，GitHub 创建 Release 曾返回 HTTP 403。为精确包提交建立 `release/package-2.13.10` 分支头，再重跑同一工作流，Release 成功发布。此修复遵循 [GitHub 对修改工作流提交的 Release 权限规则](https://github.blog/changelog/2023-11-02-github-actions-enforcing-workflow-scope-when-creating-a-release/)，没有扩大令牌权限、修改包或移动已有标签。

以后新版本首次发布前，先把 `release/package-VERSION` 固定在经过验收的包提交。工作流会校验此引用；缺失或指向不同提交时在创建 Release 前停止。已有标签必须仍指向同一提交；不同附件或元数据仍会被拒绝，不覆盖既有发布。
