# 曜核 2.11.0

窗口关闭后安静收到托盘，不再弹出“已在后台运行”的系统通知。双击托盘恢复窗口、右键退出桌面及对应后台的行为保持不变；启动失败和无法安全退出等异常仍会提示。

工作端接入中心区分三种内容：本工作区已登记的工作端、在本机发现的候选、可选接入模板。新工作区不再默认登记 Codex、ZCode、WorkBuddy、DSH。模板仅提供填写建议，不表示用户安装了对应工具。旧工作区真正使用过的工作端以兼容记录保留，显式停用优先。

发现补充运行进程的程序路径、Windows 安装登记中的有限元数据以及常见安装与命令入口，可识别 Qoder 等工具的非默认安装位置。同一程序的多个进程合并为一个候选；发现证据显示来源。扫描有数量上限和软时间预算（单次系统调用不承诺硬超时），不全盘遍历、不运行发现的程序、不读取命令行、会话、凭据或原生配置内容。未识别到的工具仍可手动添加。

“运行中”只表示本机有对应进程，不是 MCP 连接或执行能力验证。候选需保存后才能用于任务或项目；MCP stdio 模式还需要用户在原工具中完成接线。Qoder 的发现和通用交接支持不等于已经自动配置 Qoder。

主程序、MCP 桥与桌面版本均为 2.11.0（程序集 2.11.0.0）。[工作端管理](HARNESSES_2.10.md)继续说明基本操作；[2.10 历史更新](RELEASE_2.10.md)保留。当前构建验证和安装范围以交付记录为准。
