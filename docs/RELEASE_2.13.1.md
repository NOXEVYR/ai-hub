# 曜核 2.13.1 · 模型用途修正与下载入口同步

已识别角色的 VAE、文本编码器、嵌入模型不再仅因组件类型被自动归为“通用组件”。有明确名称线索时提供图片、视频或音频用途建议；证据不足保留“用途待确认”。用途与模型角色、兼容架构分别记录，名称建议不会升级为架构验证。

模型列表显示“按名称建议 · 待核验”或“证据不足 · 待确认”，悬停查看依据；模型详情中的未知架构明确显示尚无兼容依据。用户保存的人工分类优先，更新不移动模型，也不改写已有工作区规则、评分和备注。

新建工作区的规则补充模型分类约定：目录创建不等于语义分类，AI 整理建议应列明用途、角色、兼容架构与依据；通过已有分类界面保存并核对筛选结果。本版没有引入自动模型搬运或新的跨工具执行协议。扫描尚未识别组件角色的文件仍需补充角色证据，不能仅凭名称确认它就是 VAE。

2.13.0 的能力中心、Skill 与接口来源管理、右键菜单和新电脑引导继续保留，详见 [2.13.0 更新说明](RELEASE_2.13.0.md)。

## 获取与升级

最新候选包与更新清单同步到仓库默认首页和候选分支。2.12 及以上桌面版本可使用“软件更新”；2.6 等旧版没有该更新器，首次升级请下载新版程序包。先退出旧程序并备份安装目录；新包不要覆盖或删除旧 `data`、模型、环境和个人配置。

此版仍属于候选通道。历史 Release 附件保留，不代表最新候选下载。公开包不含作者的用户数据或模型；不同电脑的 Python/WebView2 依赖和真实模型运行仍需在当地验证。
