# 曜核 2.9.0 候选版

本页保留 2.9 历史记录与当时的验证边界；当前候选的工作端登记更新见 [2.10 更新说明](RELEASE_2.10.md)。历史 2.9 程序包继续保留。

此版本将公共模型资源、跨工具项目与报告索引、协作任务和能力声明放入同一工作台，并补上 Windows 系统托盘。主程序和桌面壳均为 2.9.0。源码和候选包通过 [PR #1](https://github.com/NOXEVYR/ai-hub/pull/1) 同步，历史 2.6.0 下载继续保留。

## 本次变化

- **系统托盘**：沿用金色眼形图标。关闭窗口后隐藏并继续托管；双击图标或右键“打开曜核”恢复。右键“退出曜核”停止对应安装的后台服务，再移除托盘。正在扫描、维护或处理请求时提示稍后重试，不强杀其他工具。
- **项目与报告**：按项目、工具、类别和收录状态检索，查看来源覆盖、阅读文本和打开文件夹。来源扫描支持有界续扫、异常保留历史；排除训练标注和工具内部状态。人工分类写入独立元数据，原件保留原位。
- **能力与调度**：读取 Skill 名称与简介线索，接收工作端的 MCP 能力声明，解释元数据匹配理由，校验输入并将任务送入现有队列。适配器新增四项工具，合计 17 项；MCP 会话绑定首次心跳的工作区，切换后需要重连。
- **协作与记忆**：任务领取、固定产物目录、报告登记、需审核的共享记忆，以及受保护的临时文件回收继续可用。正式报告和批准记忆保留；符合身份校验的到期临时文件仅进入 Windows 回收站。
- **界面**：曜核品牌、金色眼形与减少动态效果支持；模型列表右键操作；导航中的“大模型与语音”改为“模型管理”。

## 使用与升级

建议先将候选包解压到新的可写目录，按自己的实际路径建立工作环境。程序不包含模型、私有配置、索引库、报告、登录状态或浏览器数据。桌面入口仍为 `AI Hub.exe`，需要 Python 3.9+、.NET Framework 4.8+ 和 WebView2 Runtime；MCP 接入及配置助手要求见 [接入说明](MCP_2.7.md)。

升级已有安装时，先等待后台空闲，通过托盘退出；旧版没有托盘时只停止已确认属于该安装的桌面与后台。保留并备份整个 `data/`，替换程序文件后重新启动。运行中的 SQLite 必须使用 backup API 备份。重新加载各客户端的 MCP 连接，旧 bridge 进程不会自动更新。

退出曜核会使接入的 MCP 客户端暂时无法访问本地服务，但不会结束 Codex、ZCode、WorkBuddy、DSH 的进程或擅自取消它们的任务。再次打开曜核后按客户端要求恢复连接。

## 验证范围与待验收

发布校验记录见候选包旁的 `releases/README.md`。自动化测试在合成数据与隔离服务上运行，包内含逐文件 SHA-256 清单；未将测试通过等同于实际桌面使用验收。

仍需验收 Windows 通知区域的实际显示、右键交互与恢复窗口效果，以及各原生客户端重新连接后的真实调用。映序和棱光的直接文件交接、同机连接及三方自动串联是下一阶段适配，当前没有交付该链路。能力声明、近期心跳、任务排队均不表示模型接口已执行成功。

三款产品分别独立使用，协作可选；不要求映序、棱光依赖曜核在线或迁入共同目录。具体职责和下一步适配见 [协作边界](PRODUCT_COOPERATION.md)。
