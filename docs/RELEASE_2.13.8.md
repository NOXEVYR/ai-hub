# 2.13.8 显式退出与任务记录保护修复

本版本包含 2.13.7 的协作记录删除/恢复、报告与记忆候选提交、任务资源登记改进，并修复退出与更新被历史任务记录长期阻止的问题。公开发布状态以发布记录为准。

## 退出为何被阻止

旧版把工作区中排队或已领取的协作任务，直接作为服务忙碌的判定。任务记录保存在数据库，不会因为客户端离线自动结束。因此一条尚未收尾的历史维护任务，也会让托盘退出和本地更新一直返回“后台正在处理任务”。

新版显式退出只依据服务实际正在执行的 HTTP 数据操作、后台扫描、更新和定期维护。仍在执行时保留桌面与托盘，操作完成后可以重试；鉴权或安装身份不符仍拒绝退出。退出只关闭当前安装的服务，不终止外部 AI 工作端。

排队/已领取任务、负责人和租约在退出后原样保留。客户端在服务离线期间无法提交，重新打开后可以继续按原领取权工作；不会把任务自动完成、释放或转给其他客户端。解除工作区仍需先处理排队和已领取任务，防止切换配置时遗失工作归属。

## 验证范围

回归使用临时工作区和真实服务子进程，覆盖排队任务、近期/陈旧客户端心跳、已领取任务和租约保留、真实操作期间拒绝退出、错误安装身份和鉴权拒绝，以及受控停机清理。正式替换、备份位置和启动版本另记本地安装验收报告。

一并修复自动更新调度的时间记录与检查收尾写入竞态，全部持久副作用完成后才结束退出保护。拒绝非法 Host/Origin 的 POST 先有界丢弃请求体再关闭连接，避免 Windows 客户端偶发收到连接重置而无法读取明确的拒绝响应；不解析或执行被拒绝的请求。
