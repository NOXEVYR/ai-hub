# 模型治理 v1：有界只读诊断（源码候选）

## 入口与边界

模型管理 → **治理诊断** → **读取只读诊断**。进入页面、工作总览和程序启动均不自动触发诊断；页面只在显式点击后读取已有索引路径的文件系统元数据。没有目录遍历、权重内容读取、哈希、pickle 反序列化、模型执行、索引刷新或配置写入，也没有删除、移动、下载和清理按钮。

此增量复用分类层已有的请求内 `FileFacts` 缓存和 `st_dev:st_ino` 文件身份；没有新增实体分类树、资产数据库或扫描调度器。`FileFacts` 现在保留缺失、权限拒绝、其他不可访问和无效路径的错误分类，其原有 `stat` / `identity` 返回行为不变。

## API

`GET /api/models/governance?limit=1000&after_id=0`

- `limit`：1–5,000，默认 1,000；UI 显式请求最多 5,000。SQL 最多取 `limit + 1` 行，只探测前 `limit` 行，额外一行只用于确定是否有后续。
- `coverage.next_after_id` 非空时可带原 `coverage.scope_token` 继续读取。来源/工作区绑定变化或缺少续读凭据返回 409，非法分页返回 400。
- 复用现有 `_source_scope`，不扩大授权来源。托管工作区的显式空来源保持为空；不可用或被现有规则排除的来源不在本次诊断中，须到工作区设置核对来源健康。旧非托管模式沿用全部既有模型索引的边界。
- `coverage.whole_scope` 只表示本次覆盖当前有效来源的全部**索引行**，不代表整盘、未索引文件或不可用来源。
- 每批是独立观察。不同批次可能包含同一文件身份；**不支持跨批次相加**，也不承诺跨请求事务快照。索引在续读期间改变时应从首批重新核对。
- 只选取 `rowid_pk/path/filename/size/missing`；不返回评分、备注、来源 URL、凭据、提示词或私有媒体正文。返回的路径是本地索引路径，应按私人资产信息保管，不要公开发布。
- 页面失败保留上一份报告为历史观察，并禁用失效续读；重新读取从首批开始。离开页面后不会继续刷新，也不在本地存储持久保存报告。

## 数量与体积口径

| 字段 | 含义 |
| --- | --- |
| `indexed_rows` / `indexed_bytes` | 本批数据库行数 / 已知索引长度合计；包含缺失和别名，未知大小另计 `indexed_size_unknown_rows` |
| `present_rows` / `observed_path_bytes` | 现场普通文件行数 / 按路径行相加的已知长度；仍可能重复 |
| `identified_files` / `identified_file_bytes` | 现场取得有效文件身份、且组内元数据没有观察到变化的独立身份数 / 去重文件长度合计 |
| `identity_unknown_rows` / `unidentified_path_bytes` | 现场存在但无有效身份的行 / 已知路径长度；不擅自合并，不计入已核身份长度 |
| `same_file_alias_groups` / `alias_path_bytes` | 同一已核文件身份对应多行的组数 / 重复路径长度；**不是独立内容副本或可释放空间** |
| `hardlink_groups` | 同一已核身份具有多个不同解析后路径且链接计数大于 1 的组；单纯符号链接别名不是硬链接组 |
| `missing_rows` | 文件系统明确返回不存在/非目录中间组件；权限拒绝和其他错误不算缺失 |
| `state_conflict_rows` / `size_conflict_rows` | 现场与索引的存在性 / 已知长度不符；只报告，不修正索引 |
| `changed_identity_groups` | 同一身份在本次请求不同路径的长度或修改时间不一致；排除出已核身份长度，不以某一次值冒充精确值 |
| `reclaimable_bytes` / `allocated_disk_bytes` / `model_package_count` | 均为 `null`（未知），不能用文件长度推导卷簇分配、显存需求、可释放空间或模型包/版本数 |

`identity_coverage_complete` 仅表示本批是否存在缺失、拒绝、非普通文件、未知身份或观察到变化等未核实项。它不是生成验收、配套兼容性、内容重复证明或“可安全删除”结论。文件系统观察不是原子快照，后续变化仍可能发生。

## 非模型候选不是自动排除

只提示位置、扩展名和大小的证据：Python 包目录中的 `.pth`、零字节缓存缺失占位、很小的测试夹具、运行缓存中的普通二进制。通用 `.bin` 在证据不足时为未知；复用已有 `bin_model_evidence` 保留可辨识的权重候选。其他 `.pth` / `.bin` 不会仅因扩展名被排除。特殊私有格式保留为未知，不冒充已证实非模型。候选计数按**行**，不是物理文件数。

本阶段不读取模型头部，因此不实现主模型/投影器配套推断；不得以同目录、相近名字或参数规模猜测兼容性。完整依赖图、工作流静态解析、哈希去重与实际生成验收留待明确下一步范围。

## 处置前影响清单

1. 核对缺失、权限、身份和分类疑点；无自动修复。
2. 如怀疑独立内容重复，另行核对完整内容；同名同大小不是证明。
3. 核对工作流、加载器、配套组件、训练恢复与项目保留要求；未找到引用不等于未使用。
4. 建立路径反向映射、受影响引用和可验证的恢复方案。
5. 单独取得处置授权。当前报告固定 `safe_to_delete=false`，没有任何实际释放。

工作总览旧“候选额外占用”文案同时改为“重复路径长度 · 非可释放空间”，避免把旧重复台账中的硬链接别名当作独立空间；既有台账数据本身未改。
