# 曜核 2.13.6 项目目录与资料边界修复候选

这是本地验证候选，尚未公开发布。曜核是 AI Hub 的新版名称，程序入口与已有数据位置保持兼容。

跨工具项目默认展示明确登记或有效创建记录的项目；目录候选、模板、资料来源单独查看。候选目录和任务产物登记不能证明项目已正式登记，也不能证明工具已完成实际模型任务。搜索、来源筛选和数量统计覆盖已发现目录，分页只限制当前显示；遇到预算或访问失败会显示范围不完整。

项目列表改为紧凑表格，显示项目位置、登记依据、已记录的工具与任务、资料数量；支持查看资料、复制路径和通过现有流程登记。导航返回保留筛选和分页。工具规则、任务承接目标和成果提交来源分别注明，不把它们混作协作执行证据。

人工文档分类绑定文件快照。原文件被替换或旧标签缺少身份依据时提示重新确认，避免把旧分类认到新文件上。重叠来源去重优先当前有效的扫描记录，保留来源范围。登记库恢复警告、目录与报告盘点预算不再伪装成完整空结果。

本轮只改程序与索引展示，不自动迁移、删除、登记或重写项目原文件。模型、图库、数据库、私人配置和历史报告继续保留。实际执行验证及未覆盖范围以本轮验收记录为准。
