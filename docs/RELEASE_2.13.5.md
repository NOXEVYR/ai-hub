# 曜核 2.13.5 修复候选

本候选延续 2.13.4 的可用性修复，完善检查、编辑保护和安装生命周期。源码版本不代表正式安装或公开发布状态。

- 桌面页面成功显示后才启动自动检查等待；成功间隔一天、失败持久退避，重启不会重复冲击更新源。
- 手动检查保留立即执行；请求之前写入重试预约，保存失败则停止请求。
- 固定读取官方 main 候选清单。v2 校验平台、架构、通道、构建身份与清单摘要；旧客户端通过单独的 v1 兼容清单升级。
- 模型备注、评分、来源与设置保存按编辑版本清除标记；保存期间的新输入仍阻止安装，搜索和筛选不会误判为草稿。
- 已接入的未保存草稿及无法读取的页面状态均阻止安装。曜核自己的扫描任务、当前工作区待处理和进行中的协作任务阻止受控退出；不会按进程名关闭其他 AI 工具。
- 修复安装助手遗漏的原始 ZIP 清单兼容；旧 2.13.0/2.13.2/2.13.3/2.13.4 包需先在外部工具预览并修复清单，不能仅靠下载新包修好旧助手。
- 安装仍执行当前实例身份核验、程序白名单、逐文件备份和失败回滚，保留用户资产、数据库、配置、运行环境和本机规则。

程序包目前较小，保持完整包下载；差异下载尚未实现。后台下载限制为 50 MiB，超过上限指向手动下载。自动安装需要用户显式开启；默认只检查，安装仍经原生更新窗口或明确启用后的托盘退出动作。

验收边界：独立记录自动化回归、临时安装升级、真实窗口交互、正式安装和公开发布。外部工具绕过曜核提交的任务、未接入草稿标记的编辑器不属于本次门禁覆盖范围。旧包安装清单兼容问题见 [发布门禁](USABILITY_RELEASE_GATE.md)。
