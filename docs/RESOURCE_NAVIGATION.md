# 资源、项目与工作区的导航职责

资源导航随协作候选分层验收；源码、固定包、本地安装验证与公共发布分别记录。当前整合候选状态见 [2.13.10 整合说明](RELEASE_2.13.10.md)。

## 侧栏结构

| 层级 | 入口 | 范围 |
| --- | --- | --- |
| 总览 | 工作总览 | 工作区情况与常用入口 |
| 资源管理 | 模型管理 | 全部模型、LoRA、配套组件；语言与语音专题、使用分析、版本更新在页内切换 |
| 资源管理 | 素材管理 | 图片、视频、音频；图片生成记录作为内部专题 |
| 资源管理 | 工作流 | 可复用工作流、依赖与验证证据 |
| 项目与协作 | 跨工具项目 | 项目资料关联与原工具入口，不取代创作项目编辑器 |
| 项目与协作 | 项目与报告 | 工作报告、交付说明、方案与参考文档 |
| 项目与协作 | 能力中心 | Skill、接口与任务调度能力 |
| 项目与协作 | 协作与记忆 | 协作任务、工作端接入、已登记产物及经批准的长期记忆 |
| 工作区与维护 | 工作区设置 | 根目录、明确来源、规则与新电脑初始化 |
| 工作区与维护 | 文件空间 | 按磁盘目录浏览与查找文件 |
| 工作区与维护 | 安全区整理 | 既有可回退分类入口与整理操作 |
| 工作区与维护 | 软件设置 | 软件配置；软件更新与模型版本仍是不同操作 |

“模型资产”与“模型管理”不再作为两个相似的侧栏入口；“出图图库”不再与全媒体资源混为一谈。报表属于工作成果，Skill 属于可用能力，磁盘文件浏览属于工作区管理。

## 素材索引与预览

- `GET /api/media` 聚合现有 `files` 和 `images` 索引，不复制、移动或创建第二套素材目录。`files` 提供已登记资产扫描来源中的图片、视频、音频；`images` 补充明确登记的图片生成来源。相同路径优先保留图片生成元数据。
- 分类计数代表最近扫描的索引记录，按关键词、图片引用模型与目录共同筛选，媒体类型按钮再选择对应类别。目录选项代表该类型全部已登记来源，保留当前选择。不存在或已变化的索引记录显示为不可访问，不能预览或回收；刷新索引后更新记录。
- 空来源不会回退成全根扫描或历史全库。旧式配置也限定明确来源；失效来源保留原索引，但当前页面不展示其条目。输出来源遵守训练集、缓存、私有目录和隐藏路径的既有排除规则。
- 视频、音频由 `GET /api/media/file` 流式传输，支持单段 HTTP Range，每次最多读取 256 KiB；仅预览当前来源内已索引且仍匹配的普通文件。不支持的编码显示提示并提供打开文件夹与复制路径。
- 预览默认不自动播放；关闭、导航离开会暂停并释放媒体源，页面隐藏时暂停。未新增音视频删除权限。图片仍只允许通过既有回收接口处理已索引、未变化且处于图片生成来源中的文件。

## 兼容与产品边界

保留 `#/models`、`#/llm`、`#/analysis`、`#/updates`、`#/images` 和旧 API；专题页面正确选中所属侧栏，返回时恢复筛选、分页、滚动和详情。新主入口为 `#/assets`。

公共模型和可复用素材由曜核统一检索。映序仍拥有创作项目的素材关系与制作进度，棱光仍拥有生成画布和任务。这里的类型归类与目录来源展示不是资产搬迁、AI 写入隔离或自动报告提交。
