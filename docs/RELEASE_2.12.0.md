# 曜核 2.12.0

增加软件更新窗口，支持手动检查、下载校验与重启安装，以及可选的自动下载、退出安装。顶部软件入口与模型版本检查分开，普通浏览器只显示版本，桌面实例负责安装。

更新窗口采用深靛与金杏配色，按版本、更新说明和进度组织信息；主要操作随更新状态切换，自动更新偏好单独呈现。

更新通过固定仓库候选清单发现，包绑定提交 SHA、大小和 SHA-256。更新保留资产与用户数据，拒绝覆盖本地改动，安装前备份，失败回退程序文件；忙碌任务和页面编辑受到退出保护。

金色眼形启动场景、安静托盘、工作端发现及现有协作能力继续保留。棱光与曜核独立更新、独立运行，不共享安装器或用户数据库。

主程序、MCP 和桌面壳 2.12.0，程序集 2.12.0.0。当前为候选通道。
